# Master of Science in Artificial Intelligence

Coursework from my Master of Science in Artificial Intelligence at Grand Canyon University, by Yashu Lanki. Each folder is one course, and each week's assignment sits in its own subfolder. See the course README for project descriptions.

## Courses

### [`Mathematics-AI-Course/`](./Mathematics-AI-Course): AIT 525, Mathematics for AI

The math behind machine learning, applied to real datasets in Python.

| Week | Topic |
|------|-------|
| 01 | Linear regression: predicting fish weight (closed-form vs. SGD) |
| 02 | Matrix and vector operations on the UCI Adult dataset |
| 03 | SVD and PCA for dimensionality reduction |
| 04 | NLP document similarity (Bag of Words, TF-IDF, cosine similarity) |
| 05 | Graph theory and social influence prediction (NetworkX) |
| 06 | Fuzzy logic fuel economy prediction (scikit-fuzzy) |
| 07 | PDEs: modeling pollution spread in a river |
| 08 | Final: Bayes' theorem and a Naive Bayes spam classifier |

### [`Statistics-Data-Analysis-AI-Course/`](./Statistics-Data-Analysis-AI-Course): AIT 530, Statistics & Data Analysis for AI

Statistical reasoning and inference for AI, applied to UCI datasets.

| Week | Topic |
|------|-------|
| 01 | Probability distributions and the central limit theorem (Bike Sharing data) |
| 02 | Statistical inference and confidence intervals (Bank Marketing data) |
| 03 | Bayesian inference for online shopper conversion (Beta–Bernoulli, PyMC) |
| 04–08 | In progress |

Python dependencies are listed in [`Statistics-Data-Analysis-AI-Course/requirements.txt`](./Statistics-Data-Analysis-AI-Course/requirements.txt).
